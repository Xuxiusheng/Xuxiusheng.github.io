Fluid主题美化-增加卡片式链接

Fluid主题不支持卡片式链接展示，本人也是个前端白痴，经过Gemini3 Pro点拨，实现了一个比较简单的链接卡片。

具体的展示效果可参见About。这里把代码和配置分享出来，把以下代码包装成一个自定义js文件，并在fluid的配置中引入这个js文件，具体配置参照自定义 JS / CSS / HTML

在想要展示的页面插入以下html，大功告成！
